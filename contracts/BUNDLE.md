# 固定组合、订单与库存契约

> 状态：DDL `034` / `035` 已执行，阶段 1 + 阶段 2 已接入后台应用。

## 1. 一期范围

- 固定组合，独立父 SKU，固定区域价格。
- 组件只能引用启用的普通 SKU；每套组件数量为正整数。
- 后台运营替换配方时创建新版本，已经发布或被订单引用的版本不可修改。
- mzShop 是库存主数据源；一期只有一个业务库存地点，但结构保留 `location_id`。
- Shopify 负责前台下单以及一期的发货、退款操作；mzShop 镜像订单和状态。
- mzShop 提供极简退货入库确认，明确区分可售与不可售数量。

不包含：顾客自选组件、多仓调拨、库位/批次/波次、采购补货、头尾程、面单、条码、报关、mzShop 手工下单或主动发起退款。

## 2. 组合版本

- `shop_goods_sku.sku_type`：`normal` 普通 SKU，`bundle` 组合父 SKU。
- 组合父 SKU 不保存地点库存，不允许作为自己的组件，也不能作为另一组合的组件；一期禁止嵌套组合。
- 草稿版本可编辑；发布时校验至少一个组件、组件无重复、组件启用、数量大于 0。
- 后台将本地 `published` 状态显示为“已启用”；“启用配方”只切换 mzShop 当前有效配方，不等同于发布到 Shopify。
- 发布新版本后旧版本改为 `disabled`；同一父 SKU 同时只能有一个 `published` 版本。
- Shopify 同步使用完整组件集合覆盖远端定义；失败时本地已发布版本不回滚，但标记同步失败并禁止误报成功。
- 创建 Shopify 组件关系时必须使用 `FIXED` 和父 SKU 的区域有效售价，禁止默认按组件价格合计覆盖组合固定价；写入后校验远端父 SKU 价格。
- 历史订单永久引用下单时版本和组件快照。

## 3. 库存

- 可售库存：`on_hand - reserved - unavailable - safety_stock`，结果小于 0 时对外按 0。
- 安全库存一期启用，默认 0。
- 组合可售量：所有组件 `floor(组件可售 / 每套用量)` 的最小值。
- 订单达到 Shopify “已支付”口径后占用普通/组合组件库存；仅授权、待支付不占用。
- 发货：`on_hand` 与 `reserved` 同量减少。
- 未发货取消：减少 `reserved`；不得让任一余额变为负数。
- 退款只改变财务快照，不自动增加库存。
- 退货收货后由 mzShop 人工确认：可售数量增加 `on_hand`；不可售数量同时增加 `on_hand` 与 `unavailable`。
- 所有余额变化必须与 `stock_ledger` 同事务写入，并带唯一幂等键。
- 组合父 SKU 不写库存流水；变化全部落到组件 SKU。

## 4. Shopify 库存同步

- 每个启用店铺必须把 `default_location_gid` 映射到一个本地 `stock_location_id`。
- 普通 SKU 向 Shopify 推送 mzShop 计算的绝对可售量。
- 绝对库存使用 `inventorySetQuantities` 写入并回读校验；远端数量不一致时同步任务失败，不得误报成功。
- 固定组合父 SKU 的可售量由 Shopify 根据组件关系和组件库存计算，mzShop 不把父 SKU 当普通库存覆盖。
- 订单事件更新本地库存后，再异步推送受影响组件的最新绝对值；同一 SKU/店铺的过期任务不得覆盖较新状态。
- Webhook 以店铺和 Webhook ID 去重；不保存客户姓名、电话、地址或完整原始请求体。

## 5. 订单和售后

- 一期订单只从 Shopify 导入；不在 mzShop 创建、改价、收款或主动退款。
- 订单保存父组合行和组件行。若 Shopify 只返回组件与分组，mzShop 可按分组生成不参与库存的本地父行。
- 组件行冻结 SKU、组合版本、数量、成本、成交额、折扣和税费。
- 成交额优先使用 Shopify 实际组件分摊；不得用当前售价覆盖。
- 退款同步到组件行，使用原订单分摊金额；退款与实物退货是两个独立流程。
- 退货入库只允许普通行或组合组件行，父组合行不直接入库。

## 6. 上线门槛

1. 人工审核并执行 `034`、`035`，配置默认库存地点。
2. 明确旧 `shop_goods_sku.stock` 的初始化清单并由人工确认迁移，不自动猜测地点。
3. 配置公网可信 HTTPS Webhook 地址、HMAC 校验、事件幂等与失败重试。
4. 完成订单创建、取消、履约、退款、退货场景验证。
5. 验证重复 Webhook 不重复占用或扣减，过期库存任务不覆盖新库存。
